A make.fun bounty entry: one emoji that makes you want to book the trip.

`main.ts` (Node 22+) scores a shortlist of candidate emoji against the
bounty judges' five criteria — dream-vacation clarity first, then postcard
vividness, specificity, a spark of surprise, and readability at small size —
and writes exactly one emoji, the winner, to `/output/entry.txt`.

## Run

```sh
node main.ts
cat /output/entry.txt
```

The winner: **🏝 Desert Island** — a remote tropical island, the postcard
image of getting away from it all. Specific (an island escape, not just any
beach), vivid at a glance, and readable in every culture at any size.
